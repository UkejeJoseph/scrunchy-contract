Implement complete Solana Anchor-based smart contract system for decentralized
game asset marketplace with comprehensive deployment tooling and documentation.

Smart Contracts (3 Anchor Programs):
- Asset Registry: Manages game asset creation, metadata, ownership tracking,
  and asset transfers with NFT support
- Marketplace: Handles asset listings, rental agreements, escrow payments,
  and revenue distribution (owner/platform/game)
- Access Control: Provides fast ownership and rental verification optimized
  for SDK integration

Deployment & Automation Scripts:
- auto-airdrop-sol.sh: Automated SOL airdrop with multi-RPC endpoint support,
  local validator integration, and rate limit handling
- calculate-deployment-costs.sh: Calculate exact deployment costs per program
  using Solana CLI rent calculations
- deploy-devnet.sh: Automated devnet deployment with verification
- deploy-individual.sh: Deploy programs individually with retry logic for
  handling RPC issues
- start-local-validator.sh: Start local Solana validator for testing
